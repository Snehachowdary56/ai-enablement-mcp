# Feedback form (create it in Microsoft Forms or Google Forms)

Keep it to 4 questions so everyone answers before leaving.

1. **After today, could you build a simple n8n automation on your own?** Yes / With some help / Not yet
2. **How useful was this session?** 1 (not useful) to 5 (very useful)
3. **What is one task you would like to automate?** (short answer)
4. **What was confusing or should change?** (short answer, optional)
